Selected Research

M.Sc. Thesis · 2026–Present

Retrieval-Augmented Protein Language Models for Multi-Label Antimicrobial Peptide Classification

I am adapting retrieval-augmented protein language models to peptide sequences for multi-label antimicrobial function classification. My work compares retrieval-augmented representations with non-retrieval and frozen-retrieval baselines and uses controlled experiments to study how retrieved sequence information affects learned representations and downstream classification.

INSF-Funded Research Project · 2024–Present · Manuscript in Preparation

Efficient MobileNet-Based Architecture for 3D Medical Image Segmentation

I am contributing to the design and evaluation of a MobileNet-based 3D CNN for volumetric medical image segmentation. The architecture uses inverted bottleneck blocks and explores input-adaptive dynamic convolutions, target-spacing, and stem-stride design for efficient volumetric inference. I also contribute to experimental analysis and manuscript preparation.

  • 3D Deep Learning

  • Efficient CNNs
  • Dynamic Convolution

B.Sc. Thesis · 2024–2025 · Grade: 20/20

Feature-Based Knowledge Distillation with CBAM Attention

I developed a teacher–student knowledge-distillation framework on CIFAR-100 using a ResNet-56 teacher and ResNet-20 student. The method combines CBAM-guided intermediate feature matching with conventional logit distillation to study attention-guided feature-level and prediction-level knowledge transfer.

  • Attention

  • Representation Transfer
  • PyTorch

Selected Technical Projects

Multilabel Antimicrobial Peptide Classification Benchmark

Built a controlled five-label antimicrobial peptide classification benchmark on ESCAPE. I compared seven frozen protein/peptide language-model encoders with six biological sequence representations under a shared MLP classifier, implemented overlap auditing and leakage-controlled splits, cached embeddings, used reciprocal-fold ensembling, and evaluated performance under severe label imbalance with multiple global and per-label metrics.

Technical themes: PyTorch · Transformers · scikit-learn · Benchmarking · Representation Learning · Reproducible Evaluation

Kolmogorov–Arnold Network from Scratch

Code ↗

Implemented a Kolmogorov–Arnold Network from scratch in PyTorch, with learnable univariate edge functions represented using cubic B-spline bases and a learnable SiLU residual component. I implemented B-spline evaluation with iterative Cox–de Boor dynamic programming, added correctness and gradient-flow tests, and benchmarked the model against width- and parameter-matched MLP baselines.

Technical themes: PyTorch · B-Splines · Neural Network Architecture · Dynamic Programming · Gradient Testing

Autograd Engine and Neural Network from Scratch

Code ↗

Implemented a scalar reverse-mode automatic differentiation engine with computational-graph construction, differentiable scalar operations, topological backpropagation, and gradient accumulation. I then built Neuron, Layer, and MLP abstractions on top of the engine with loss computation and gradient-descent updates.

Technical themes: Python · Reverse-Mode Autodiff · Backpropagation · Computational Graphs · Neural Networks

Image Reconstruction via Regularized Inverse Problems

Code ↗

Modeled image degradation as a linear inverse problem with Gaussian blur, motion blur, and additive noise. I compared unregularized LSQR, zero-order Tikhonov regularization, Wiener filtering, and Richardson–Lucy deconvolution and analyzed reconstruction quality and parameter sensitivity using PSNR and SSIM.

Technical themes: NumPy · SciPy · Inverse Problems · Numerical Optimization · Image Reconstruction

Dimensionality Reduction for scRNA-seq Data

Code ↗

Built preprocessing pipelines for multiple single-cell RNA-seq datasets and compared PCA, t-SNE, UMAP, and a PyTorch VAE. I evaluated higher-dimensional representations through downstream K-means clustering using ARI, AMI, and Silhouette Score.

Technical themes: Representation Learning · VAE · PCA · UMAP · scRNA-seq · PyTorch
