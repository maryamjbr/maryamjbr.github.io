M.Sc. Thesis · 2026–Present

Retrieval-Augmented Protein Language Models for Multi-Label Antimicrobial Peptide Classification

I am adapting a retrieval-augmented protein language model to peptide sequences for multi-label antimicrobial function classification. I compare retrieval strategies with non-retrieval and frozen-retrieval baselines, using controlled experiments to study how retrieved sequences affect learned representations and classification.

Efficient MobileNet-Based Architecture for 3D Medical Image Segmentation

I am contributing to the design and evaluation of a MobileNet-based 3D CNN for volumetric medical image segmentation. B.Sc. Thesis · 2024–2025 · Grade: 20/20

Feature-Based Knowledge Distillation with CBAM Attention

I developed a teacher–student knowledge-distillation framework on CIFAR-100 with a ResNet-56 teacher and ResNet-20 student. It combines CBAM-guided matching of intermediate features with logit distillation. CBAM is used during training; the final student remains a standard ResNet-20 at inference.

Selected Technical Projects

Multilabel Antimicrobial Peptide Classification Benchmark

Built a five-label antimicrobial peptide benchmark on ESCAPE. I compared seven frozen protein and peptide language-model encoders with six biological sequence representations under the same MLP classifier, then evaluated the biological representations with Random Forests. The pipeline includes overlap auditing, leakage-controlled splits, cached embeddings, reciprocal-fold ensembling, and per-label evaluation under severe class imbalance.

Kolmogorov–Arnold Network from Scratch

Implemented a Kolmogorov–Arnold Network from scratch in PyTorch, with learnable univariate edge functions represented using cubic B-spline bases and a learnable SiLU residual component. I implemented B-spline evaluation with iterative Cox–de Boor dynamic programming, added correctness and gradient-flow tests, and benchmarked the model against width- and parameter-matched MLP baselines.

  • PyTorch
  • B-Splines
  • Neural Network Architecture
  • Dynamic Programming

Autograd Engine and Neural Network from Scratch

Implemented a scalar reverse-mode automatic differentiation engine with computational graphs, differentiable operations, topological backpropagation, and gradient accumulation. I built Neuron, Layer, and MLP abstractions on top, then trained the network with MSE loss and gradient descent and visualized the graph with Graphviz.

Image Reconstruction via Regularized Inverse Problems

Modeled image degradation as a linear inverse problem with Gaussian blur, motion blur, and additive noise. I compared unregularized LSQR, zero-order Tikhonov regularization, Wiener filtering, and Richardson–Lucy deconvolution and analyzed reconstruction quality and parameter sensitivity using PSNR and SSIM.

Dimensionality Reduction for scRNA-seq Data

Built dataset-specific preprocessing for selected Deng, Chu, and PBMC68k single-cell RNA-seq data, then compared PCA, t-SNE, UMAP, and a PyTorch VAE. I evaluated the reduced representations with downstream K-means clustering using ARI, AMI, and Silhouette Score.
